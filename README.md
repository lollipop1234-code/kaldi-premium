# Kalda Premium Website Concept

Ný static heimasíða fyrir Bruggsmiðjuna Kalda. Verkefnið er byggt sem hraður, sjálfstæður vefur með:

- gagnvirkum hero með canvas-hreyfingu
- bjóravali sem breytir bragðnótum og sjónrænum karakter
- upplifunarhluta fyrir Bjórböðin, Hótel Kalda og brugghúskynningar
- þjónustusíðu fyrir kynningar, sérmerkingar, dæluleigu og kaup beint frá verksmiðju
- tilbúnum mailto-fyrirspurnum fyrir helstu erindi

## Keyrsla

Opnaðu `index.html` beint í vafra, eða keyrðu einfaldan static server í þessari möppu.

```powershell
python -m http.server 4173
```

## Uppsetning

```text
index.html
styles.css
script.js
assets/
```

## Myndefni

Myndirnar í `assets/` eru unnar úr myndefni á núverandi vef Kalda og eru hugsaðar fyrir concept/prototype vinnu. Fyrir lokabirtingu þarf að staðfesta endanleg réttindi, myndgæði og vörulínu.
